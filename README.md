# Zweite Lesart · Gotische Malerei 1140–1510

Michel Hérubels „Die Malerei der Gotik“ (1966) als Datenbestand: 816 Einträge, die sich in vielen Ansichten zugleich filtern und vergleichen lassen.

## Dateien

- `index.html` ist die Oberfläche (Version 152). Unten rechts läuft eine kleine Beamer-Ansicht mit, die jedem Filter folgt.
- `beamer.html` ist die Beamer-Ansicht. Sie zeigt die gefilterten Werke als Netz und alle paar Sekunden ein Werk im Großbild.

## Beamer

Das Beamer-Feld unten rechts hat drei Knöpfe:

- **Groß** zeigt dieselbe Ansicht bildschirmfüllend. Mit „Verkleinern“ oder Esc geht es zurück.
- **Zweiter Bildschirm** öffnet den Beamer als eigenes Fenster. Dieses Fenster auf den zweiten Bildschirm oder Beamer ziehen und dort auf Vollbild schalten. „Zurückholen“ oder das Schließen des Fensters holt die kleine Ansicht zurück.
- **–** klappt das Feld ein.

Die Bilder kommen von Wikimedia Commons (gemeinfrei) und brauchen eine Internetverbindung.

## Bedienung

Gesteuert wird am Rechner mit der Maus. Jede Farbe, jeder Name und jede Zeitspanne ist ein Filter, der auf alle Ansichten und den Beamer zugleich wirkt.
